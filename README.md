# BJ Catalogue — website + installable phone app

**https://aowu-hub.github.io/bj-catalogue/** — search the BJ catalogue; https://aowu-hub.github.io/bj-catalogue/view.html = catalogue page viewer.
Install: Android Chrome → **Install** (pill at the bottom or ⋮ → Install app) · iPhone Safari → **Share ⬆︎ → Add to Home Screen**.

This repo holds only the BUILT pages (public). The page source and the data (Apps Script data door) are private.
Built by `tools/build-site.mjs` in the private repo — never edit these files by hand. Version: v2026.11.13-0815
